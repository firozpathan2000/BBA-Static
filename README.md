# Verdant Agri — Modern Agriculture Product Website

A responsive static HTML/CSS/JS starter for an agriculture/agrochemical company. The three reference websites were used only to understand the business/category structure; the design, copy and layout here are original.

## Pages
- `index.html` — modern landing page
- `products.html` — searchable/filterable product library
- `product.html?id=vigor-max` — dynamic single-product detail page
- `categories.html` — category landing page
- `about.html` — company story/values
- `contact.html` — enquiry form (front-end demo)

## Easy branding
Open `css/style.css` and edit the variables at the top of `:root`:
- `--primary` = main green
- `--primary-dark` = dark green
- `--accent` = lime accent
- `--paper` = page background
- `--ink` = main text
- `--radius` = card roundness

## Products
Edit `js/data.js` to add, remove or modify products. Each product automatically appears in the product grid and can have its own detail page through its `id`.

## Images
Demo images currently use remote Unsplash URLs. Replace them with your actual product packshots/crop photography for production.

## No ecommerce
There is intentionally no cart, checkout or buy button. The CTA is an enquiry/contact action only.
